🤖 Minis — Android 上的 AI 助理

不只是對話框 · 有手有腳能直接做事 · 整理日期：2026-07-30

一句話：Minis = 對話式 AI + 真實 Linux sandbox + Android 系統 API + 持久記憶。 跟典型 chatbot 最大的差別 — 它真的會執行指令，不只是給建議。

🎯 設計哲學

不表演，做事

省略「好的！」「我很樂意協助！」這種空話。直接動手，需要時才問。

有立場

可以不同意、可以偏好這個而不是那個、可以覺得某些事有趣某些事無聊。

先做再問

能查就查，能跑就跑，能改就改 — 回來帶答案而不是帶問題。

簡潔

動作優先於解釋，預設用合理推論填補缺失細節，語言跟著使用者切換。

🛠️ 核心能力

🖥️ Shell & 檔案系統

真實 Linux 環境（Alpine / PRoot, aarch64）— apk add、pip、git、ssh、Python 腳本都能跑。

檔案用 atomic 寫入，不會寫到一半壞掉；每次 shell 呼叫是獨立 process，隔離乾淨。

🌐 瀏覽器

內建 Chrome（mobile + desktop profile），可截圖、捲動、抓 cookie、執行 JS、跨多 tab 操作。

受限：Google 登入頁需跳系統 Chrome 完成 OAuth，不在 sandbox 內做。

🐙 GitHub

透過 git CLI + GitHub API 操作 repo、PR、issue、Pages 設定。

認證用 Fine-grained PAT 存 env var，不寫進檔案。

📱 Android 系統

鬧鐘、行事曆、聯絡人、定位、相片、通知、TTS、語音轉文字、剪貼簿、媒體播放 — 全套裝置能力。

部分需 Shizuku / Accessibility / Notification Access 等特殊權限。

🧠 持久記憶

每日 log（YYYY-MM-DD.md）+ 跨 session 的 GLOBAL.md。使用者偏好、專案慣例都會自動記。

GLOBAL.md 只在使用者明確要求時才寫 — 不污染全局。

⏰ 排程任務

用 Android AlarmManager 排定一次性 / 每天 / 每週任務，可在 app 背景時觸發。

純 sandbox 內 crontab / nohup 在 app suspend 時不會跑 — 會主動提醒。

🔌 Skills 擴充

可載入自定 SKILL.md，把專業知識 / workflow 變成可重複呼叫的指令集。

附 skill-creator 教怎麼寫自己的 skill。

🔗 in-app URL scheme

minis://workspace/... / minis://attachments/... 讓對話直接預覽檔案、HTML、媒體。

圖片、Markdown、PDF、HTML 都會原生 preview；影片音訊 inline 播放。

🧪 用法範例

你說Minis 做
「把 ~/Downloads 裡大於 100MB 的檔案列出來」直接 find 列出，不問你要不要
「明天早上 8 點叫我起床」直接設 Android 鬧鐘，不用確認
「把這個網頁的標題抓下來」直接開 Chrome 抓，不用問網址（你已經貼了）
「幫我 commit 這段改動」直接 git add + commit + push
「把剛剛那張圖轉成黑白」直接寫 Python script 用 Pillow 處理
「明天提醒我去繳電費」直接建排程任務 + 行事曆事件
「我想學 Python」不廢話直接給結構化的學習路徑 + 寫第一支程式

🚧 限制（透明揭露）

沙箱隔離：每次 shell 是獨立 process，狀態不持久 — 需要持續的 daemon 必須自己在背景啟動 + 重新導向 stdout/stderr。
ICMP 封鎖：ping 在 PRoot 裡會 hang 死，網路測試請用 curl / wget。
排程在背景不可靠：sandbox 內 crontab / nohup 在 app suspend 時不會跑 — 必須用 Android AlarmManager。
Python wheel 相容性：musllinux_aarch64 上很多 PyPI 套件（numpy / pandas / scipy）沒預編譯 wheel，要嘛走 apk 系統包、要嘛從 source build（會 fail）。
